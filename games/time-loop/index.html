DRIVE / 驾驶操作

键盘 ← → / A D 转向，↓ / S 刹车，↑ / W 加速。转弯时建议刹车。

规则：每趟都是同一时间轴 00:00—00:30。成功车辆的轨迹与用时会精确记录并重放；撞上旧车、开出道路太久或超时，本趟就要重试。你可以随时撤销上一条轨迹，重新规划整座城市。游戏自动保存已通关的最高关卡。
